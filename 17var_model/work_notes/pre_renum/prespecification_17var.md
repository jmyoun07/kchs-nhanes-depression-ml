## 1. 개정 사유 (Protocol amendment rationale)
- 원 프로토콜 Table 1은 조화 예측변수 14개를 사전지정했다.
- 지도교수가 변수 재선정을 승인하였고, 연구자는 **외부검증(KCHS 개발 → NHANES 무재적합 적용) 설계는 그대로 유지**하고 **두 데이터 공통 변수만 확장**하기로 결정했다. 즉 §2.10 외부검증 전략·§2.4 결과정의·§2.8 모델개발 스펙은 **변경 없음**. Table 1(예측변수 목록)만 개정한다.
- 확장 후보는 KCHS 전체 616개 개념을 NHANES 코드북 전수 대조하여 도출했고(Codex 교차검증), **"양 주기 공통 + KCHS 다년 조사 + 결과와 비순환"** 조건을 모두 통과한 것만 채택했다.

## 4. 분석 계획 (기존 프로토콜 유지 - 변경 없음)
- **결과**: PHQ-9 총점 ≥10 (양국 동일). 민감도: ≥5, 연속점수.
- **개발**: KCHS 2017-2025. 알고리즘 3종(elastic net / random forest / LightGBM). **주모델은 내부 CV 기준으로 사전 선택**(CV-AUROC → |CV-OOF 보정slope-1| → 간명성). 외부 성능을 보고 모델을 고르지 않는다.
- **전처리**: 개발셋에서만 학습 → 외부에 그대로 적용(누수 금지, §2.6).
- **평가**: 복합표본 가중, PSU-군집 부트스트랩 CI (§2.8·2.9).
- **외부검증**: KCHS 학습모델을 NHANES에 **재적합 없이** 적용(§2.10). pre/post 분리 + 절편/기울기 재보정.
- **비교 기준**: 확장 17변수 모델 vs 기존 14변수 모델을 **내부·외부 모두** 병기 보고한다(확장의 순효과를 정직하게 드러내기 위함).

## 5. 사전 선언 (Pre-declared expectations)
- 신규 3개는 **중간 강도** 예측변수로 예상되며, 내부 AUROC는 소폭 상승(0.824 → 0.83 내외) 예상.
- **외부 AUROC 0.80 도달은 기대하지 않는다.** 외부 격차의 원인은 변수 수 부족이 아니라 한·미 간 concept shift로 이미 확인되었다(레버 실험: 결측·가중·알고리즘 조정으로도 외부 ~0.75 불변).
- 확장 후 외부가 개선되지 않더라도 **그 결과를 그대로 보고**한다. 개선이 없다는 것 자체가 "격차는 변수가 아니라 전이 문제"라는 근거가 된다.
