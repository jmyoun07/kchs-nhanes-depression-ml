## ★ 2026-07-10 후속: H1 해결 (프로토콜 준수로 0.80 돌파)
- **문제**: 조화모델이 0.76으로 H1(≥0.80) 미달로 보였음.
- **원인**: 자가건강을 제외했기 때문. 이유는 "NHANES에 없음"이었으나 **엉뚱한 파일(HSQ)만 확인한 오판**.
- **해결**: 자가건강은 NHANES **`HUQ·HUQ010`**(General health 5단계)에 실재(P_HUQ 결측0%·HUQ_L 확인). Table 1의 파일오류 정정([protocol_erratum.md](protocol_erratum.md)). §2.5 교집합 충족 → **프로토콜 Table 1대로 14변수 조화모델 복원**.
- **결과**: 내부 **AUROC 0.824**(elastic net 0.802·RF 0.821 — 셋 다 >0.80) → **H1 충족.** 외부도 상승: pre **0.745**·post **0.754**(자가건강 전 0.70). 경량 4문항 0.817. SHAP #1=자가건강(ρ=0.988). 민감도서 PA·음주 제외해도 0.823(강건).

# Codex 적대적 교차검증 — 야간 총평 (2026-07-09 심야)

독립 리뷰어(Codex, GPT-5.x)를 **깐깐한 JMIR 통계리뷰어/코드감사자**로 세우고, 각 지적을 Claude가 **적대적으로 재검증**(실제 코드·데이터 대조)해 **진짜 결함만** 수정하는 사이클을 **4라운드** 수행. Round 3·4 연속 신규 실질결함 없음 → **수렴 종료**.

## 라운드 요약
| R | 발견 | 핵심 조치 |

| 1 | 25개 지적 | PHQ 코딩 전연도 1–4 확인(안전)·핵심변수 강건 검증. **재보정 in-sample→교차적합**, holdout 선택누수 제거, naive CI→**PSU-군집**, DCA 원본확률 |
| 2 | 심층(PA·가중) | **PA `fillna(0)` 오분류 버그 + 구성개념 비교불가 → PA·음주 primary 제외(10변수)**, 가중치 연도정규화 |

| 4 | 최종 | 공정성 **군집CI**, **가중 Table3**, **DPQ 무응답 특성화**, 연령 민감도 → **수렴 확정** |

## 검증으로 확정된 정직한 결론 (좁게 표현 시 방어가능)
- **외부 판별력 modest**: AUROC 내부 0.756 → pre **0.703(0.68–0.72)** / post **0.695(0.67–0.72)** (PSU-군집 CI).
- **보정은 전이 시 악화**(기울기 0.66–0.67, post CITL 0.96).
- **local 교차적합 재보정은 회복**(slope→1·CITL→0) — 단 **목표시기 라벨 필요**.
- **pre→post 전이 재보정: 기울기는 교정(1.01)되나 CITL 0.44 잔존** — 팬데믹 이전 재보정만으론 이후 유병률 수준 못 잡음(코로나 전후 질문에 직접 답).
- **임상 유용성 미확립**(PPV 내부0.06·pre0.10·post0.15, DCA 미확정).
- SHAP 일치도 ρ0.94는 **기계적**(동일모델 양측적용) → 서술적.
- 국내모델 0.89는 **스트레스(근접순환)** 기인 → 동시증상 스크리너로 표기.

## 반드시 인지할 위협 (코드결함 아님, 한계)
- ⚠️ **NHANES post DPQ 무응답 32.7%**(pre 14.3%), 저학력·아시아계·젊은층 높음 → **post 유병률·외부검증에 선택편의**. 결과는 **완전례(complete-case) 한정**으로 명시 유지 필수. (1-2문항 결측 person-mean은 유병률 <0.1%p 변화 — 대부분 전체무응답이라 복구불가)
- 연령 20+ 대상(18-19 제외; 젊은층 유병 높아 소폭 과소).
