## 1. 연구 목적 및 가설

**목적(aims).**
1. KCHS에서 현재 우울증(PHQ-9 ≥10) 예측 ML 모델 개발
2. 미국 NHANES에서 지리적(국가 간) 외부검증
3. NHANES pre/post-COVID 각각에서 시간적 외부검증 및 재보정 효과 정량화
4. 디지털 자가문진용 경량(5–10변수) 모델 도출

**사전 가설(protocol 기준).**
- H1: 전체 모델 내부 AUROC ≥ 0.80
- H2: 외부검증에서 판별력(AUROC)은 임상적으로 유용한 수준 유지, 보정(calibration)은 악화 가능
- H3: 재보정(절편/기울기)이 보정을 유의하게 개선
- H4: 경량 모델의 성능 손실은 임상적으로 무시 가능한 수준(소폭)

## 2. 연구 설계
후향적 이차자료 기반 임상예측모델 개발 + 외부검증. 개발=KCHS, 외부검증=NHANES(지리적) 및 NHANES pre/post-COVID(시간적).

## 3. 데이터 소스
- **개발:** 한국 지역사회건강조사(KCHS, KDCA), 만 19세 이상, 층화·군집·가중 복합표본. **PHQ-9 수집 연도만 사용** → 연도는 `[확인필요: 이용지침서 Part 4로 확정]`.
- **외부검증:** 미국 NHANES(NCHS). pre-pandemic = 2017–2020.3(`P_` 결합파일), pandemic/post = 2021.8–2023.8(`_L` 파일). 성인 분석.

## 4. 연구대상 및 적격성
- **포함:** 두 설문 공통 하한연령 이상 성인, PHQ-9 9문항 모두 응답.
  - 공통 하한연령 = `[확인필요]` (권장: 만 20세; KCHS ≥19, NHANES DPQ ≥18 → 보수적 상한 채택). 민감도 분석에서 대안 연령 검토.
- **제외:** PHQ-9 문항이 분석 임계 이상으로 결측인 경우.
- **주분석 유지 / 민감도에서 검토:** 임신부, 우울증 기왕력(의사진단) 응답자.

## 5. 결과변수(Outcome)
- **주 결과:** 현재 우울증 = PHQ-9 총점 ≥ 10 (9문항 각 0–3, 양 설문 동일 산출).
- **민감도:** 컷오프 ≥5, 연속 점수.
- **결측 규칙:** PHQ-9 문항 결측 `[확인필요]` (권장: 0개 결측만 주분석 포함; 1–2개 결측 시 person-mean 대체는 민감도에서만).

## 6. 예측변수 (조화 세트)
외부검증 가능한 **두 설문 교집합** 변수만 사용. 개념 매핑은 `docs/harmonization_dictionary`(원 프로토콜 Table 1) 참조. 요약:

나이, 성별, 교육, 가구소득(설문 내 상대 분위수), 혼인/동거, 독거, 흡연(never/former/current), 음주(현재 음주+위험음주), 신체활동(유산소 권장 충족), 수면시간, BMI(연속형 주사용), 자가건강(5단계), 고혈압(자가진단), 당뇨(자가진단).
- **인종/민족(RIDRETH3):** 예측변수 아님 → **NHANES 공정성 하위그룹 분석 전용**.
- **KCHS 전용 변수(스트레스 인지, EQ-5D, 사회적 지지, 주관적 인지저하):** 조화 모델 제외 → **국내(KCHS-only) 보조 모델 및 민감도 전용**.

**조화 주의(사전 규정).**
- 소득: 절대액 아님 → **설문 내 5분위(상대순위)**로 정의.
- BMI: KCHS 자가보고 vs NHANES 실측 → **연속형 BMI를 주사용**, 아시아 기준 범주는 민감도.
- 음주·신체활동: 도구 상이 → 보수적 공통 정의로 축소(§14 참조), 잔차는 민감도로 정량화.
- 주기별 변수명: 혼인 DMDMARTZ(P_/L) vs DMDMARTL(≤2018), 음주 ALQ 항목 → `01_harmonize.py`에서 주기 분기 처리.

## 7. 표본수 / 사건수
- 개발: KCHS 규모상 검정력 제약 없음 → 과적합 통제·보정 안정성이 관건.
- 외부검증: **NHANES 시기별 우울증 사건수**가 보정·DCA 정밀도를 좌우 → 사전 산출(Appendix A #3). EPV 및 보정지표 신뢰구간 폭을 사전 점검.

## 8. 결측 처리
- 개발셋: 다중대체(MICE) 또는 트리 자체 처리. 대체 방식 `[확인필요]` (권장: 연속형 예측변수는 MICE, 트리 모델은 자체 처리 병행 비교).
- **누수 방지(핵심 규정):** 대체·전처리 파이프라인은 **개발셋(KCHS)에서만 학습**하고, 각 외부셋에 **그대로 적용**한다. 외부셋 정보로 전처리를 재적합하지 않는다.

## 9. 모델 개발

### 9.1 알고리즘
페널티 로지스틱(elastic net), 랜덤포레스트, 그래디언트 부스팅(XGBoost/LightGBM). (선택) 얕은 신경망.

### 9.2 데이터 분할
KCHS를 **층화 분할**: 개발용 / 내부검증용 hold-out.
- 분할 비율 `[확인필요]` (권장: 개발 80% / hold-out 20%, 결과변수로 층화).
- 튜닝은 **개발분할 내부에서 반복 층화 k-fold CV**(권장: 5-fold × 5회 반복). hold-out은 튜닝에 일절 사용하지 않음.

### 9.3 불균형 처리
class weighting / focal loss / (필요시) SMOTE. **학습 fold 내부에서만** 적용(검증 fold·hold-out·외부셋에는 미적용). 주 방식 `[확인필요]` (권장: class weighting 우선, SMOTE는 민감도).

### 9.4 복합표본 가중치 (사전 규정)
- **주 방식(권장):** 비가중 학습 + **가중 평가**(복합표본 설계 반영한 성능 추정).
- **민감도:** 가중 학습.
- `[확인필요]`: 위 주/민감도 배정 확정.

### 9.5 ★ 주 모델(primary model) 선택 규칙 — 사전 확정
1순위: **개발분할 CV 평균 AUROC 최대** 모델.
동률(ΔAUROC < 0.005) 시 → 2순위: **보정 기울기(calibration slope)가 1에 가장 근접**.
그래도 동률 → 3순위: **간명성·해석성 우선(elastic net > 트리 > NN)**.
> hold-out·외부 성능은 선택에 사용하지 않는다(선택은 개발분할 CV로만).

### 9.6 작동 임계값(threshold) 선택 규칙 — 사전 확정
스크리닝 도구 특성상 민감도 우선.
- 규칙 `[확인필요]` (권장: **보정 후** 개발셋에서 **민감도 ≥ 0.85를 만족하는 최대 특이도 지점**). 대안: Youden J. → 민감도 분석에서 비교.

## 10. 성능 평가지표
- **판별력:** AUROC, AUPRC (95% CI, 부트스트랩).
- **보정(외부검증 핵심):** 보정곡선, 보정 기울기·절편, Brier, ECE.
- **임상 유용성:** 의사결정곡선(net benefit), 임상 관련 임계확률 구간 `[확인필요: 예 0.05–0.30]`.
- **작동 특성:** 선택 임계값에서 민감도·특이도·PPV·NPV.

## 11. 외부검증 전략
- **지리적:** KCHS 학습 모델을 **재적합 없이** NHANES에 적용.
- **시간적(COVID):** NHANES pre(2017–2020.3), post(2021.8–2023.8) **각각 별도** 평가.
- 모든 외부 지표는 NHANES 복합설계(strata/PSU/weight) 반영.

## 12. 재보정(Recalibration) — 사전 규정
- **발동 조건 `[확인필요]`** (권장: 보정 기울기 ∉ [0.8, 1.2] **또는** |보정 절편| > 0.2).
- **방법(단계):** ① 절편만(calibration-in-the-large) → ② 절편+기울기(로지스틱 재보정) → ③ Platt/temperature scaling 비교.
- **원칙:** **예측변수 계수는 재추정하지 않음**(보정만 갱신 = 배포 친화적).
- 재보정 전/후 지표를 모두 보고, 회복분 정량화.

## 13. 해석성·공정성·경량 모델
- **SHAP:** 전역/지역 기여도. **KCHS↔NHANES 상위 예측변수 순위 일치도**(Spearman 등)로 전이가능성 기전 검토.
- **공정성:** 성별·연령·교육·소득·(NHANES)인종/민족별 AUROC·보정·오류율. 플래그 기준 `[확인필요]` (권장: 하위그룹 AUROC가 전체 대비 |Δ|>0.05 시 표기).
- **경량 모델 규칙 `[확인필요]`** (권장: SHAP 중요도 상위부터 추가하며 전체 대비 ΔAUROC < 0.02 유지되는 최소 변수집합, 5–10개 상한).

## 14. 민감도 분석 (사전 목록)
결과 컷오프(≥5/≥10) · 가중치 방식(가중/비가중 학습) · 자가보고 vs 실측 BMI · 우울증 기왕력 제외 · 조화 연령 하한 대안 · 대체 대체법 · 음주/신체활동 대안 정의.

## 15. 소프트웨어
Python(scikit-learn, xgboost, lightgbm, shap, statsmodels, dcurves), R(rms, dcurves, survey). 코드·시드·패키지 버전 공개.

## 16. 재현성·공개
OSF 사전등록, 공개 저장소에 전처리 코드·하이퍼파라미터 그리드·모델카드·**변수 조화 사전** 공개. **KCHS 원시자료는 비공개(재배포 금지)**, NHANES는 재다운로드 가능.

## 17. 윤리
KCHS·NHANES 모두 공개·비식별 이차자료. 기관 IRB 면제/승인 확보, 재식별 시도 없음.
