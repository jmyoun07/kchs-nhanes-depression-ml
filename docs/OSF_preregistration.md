# OSF 사전등록 (Pre-registration) — 초안

> 작성일 2026-07-07 · 이 초안을 OSF Prereg 양식에 붙여넣어 등록. **등록 완료 후에만 모델링을 시작한다.**
> 상세 통계 규칙은 `docs/SAP.md` 참조(등록 시 SAP 파일 첨부 권장).

## 1. 제목
우울증 스크리닝 ML 모델의 개발(KCHS)과 국가 간·COVID 전후 외부검증(NHANES): 디지털 트리아지 도구

## 2. 저자
`[확인필요: 성명·소속·ORCID]`

## 3. 연구 유형 / 데이터 상태 (기존 데이터 고지 — 중요)
기존(이차) 공개 설문자료 이용 연구.
- **NHANES:** 공개 다운로드 가능. **본 등록 시점에 결과(우울증) 관련 분석을 수행하지 않았음.** 등록 이후 외부검증에 사용.
- **KCHS:** KDCA 승인(신청·심의) 후 접근. 등록 시점에 원시자료 미열람 `[해당 여부 확인]`.
> 데이터에 대한 사전 지식: `[확인필요 — 예: 선행연구로 알려진 우울증 유병률 수준 외에 본 표본의 결과-예측변수 관계를 사전 분석한 바 없음]`.

## 4. 가설
- H1: 내부 AUROC ≥ 0.80
- H2: 외부검증에서 판별력은 임상적으로 유용하게 유지되나 보정은 악화 가능
- H3: 절편/기울기 재보정이 보정을 유의하게 개선
- H4: 경량(5–10변수) 모델의 성능 손실은 임상적으로 무시 가능

## 5. 설계
개발–외부검증 설계. 개발=KCHS(복합표본), 외부검증=NHANES 지리적 + NHANES pre/post-COVID 시간적. 결과는 양 설문 동일한 PHQ-9 ≥10.

## 6. 변수
- **결과:** PHQ-9 총점 ≥10 (9문항 0–3).
- **예측변수(조화 세트):** 나이·성별·교육·소득(상대분위)·혼인·독거·흡연·음주·신체활동·수면·BMI(연속)·자가건강·고혈압·당뇨. (원 프로토콜 Table 1 = `docs/harmonization_dictionary`)
- **인종/민족:** 예측변수 아님, NHANES 공정성 하위그룹 전용.

## 7. 분석 계획 (요약 — 상세는 SAP)
1. KCHS 층화 분할(개발/hold-out), 반복 층화 k-fold CV 튜닝.
2. elastic net / RF / GBM 학습, 불균형·가중치 사전 규정대로 처리.
3. **주 모델 선택 = CV AUROC → 보정기울기 → 간명성**(사전 확정, SAP §9.5).
4. 내부검증(판별·보정·DCA·작동특성) → NHANES 지리적·시간적 외부검증.
5. 보정 저하 시 **절편/기울기 재보정(계수 재추정 없음)**, 전/후 비교.
6. SHAP·공정성 하위그룹·경량 모델 도출.

## 8. 표본수 / 사건수
개발은 KCHS 규모상 검정력 제약 없음. 외부검증 정밀도는 NHANES 시기별 우울증 **사건수**가 좌우 → 등록 전 사전 산출(SAP §7).

## 9. 결과-중립 기준 (Outcome-neutral criteria)
- 모델 선택·임계값·재보정 규칙은 **결과 성능을 보기 전에** 확정(SAP 부록 결정표 D1–D13).
- 제외 기준은 결과와 무관하게 적용(적격성 §4).

## 10. 통제·기타
- 전처리·대체는 개발셋에서만 학습 후 외부셋에 그대로 적용(누수 방지).
- 코드·하이퍼파라미터·모델카드·변수 조화 사전 공개. KCHS 원시자료는 비공개.
