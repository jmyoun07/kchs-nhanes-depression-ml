# KCHS 데이터 정리 노트 (원시자료 실측 기반)

작성: 2026-07-08 · 원시자료 SAS 메타데이터를 직접 읽어 확정한 내용.

## 1. 폴더 구조 (정리 완료)
```
data/raw/kchs/
  2008/ … 2025/           연도별 폴더
    data/                 원시자료 (.sas7bdat)
    guide/                이용지침서 (코드북)
    survey/               조사표
  _원본압축_보관/          받은 zip 원본 (필요없으면 삭제 가능)
```
- SAS 19개 이동, zip 33건 해제(중복 2건 제외), 총 236개 문서 추출.
- 파일 버전 참고: `chs10_all_v2`, `chs20_all_re`, `chs08_all_v01`, 2019는 `chs19_all` + `chs19_ctv` 2종.

## 2. ★ 결과변수(PHQ-9) — 확정
KCHS의 **PHQ-9 9문항 = `mtb_07a1` ~ `mtb_07i1`** (라벨 "우울증상유병_…").

| 변수 | PHQ-9 문항 |
|---|---|
| mtb_07a1 | 일에 대한 흥미나 재미 없음 |
| mtb_07b1 | 우울감 혹은 절망감 |
| mtb_07c1 | 잠들기 어렵거나 많이 잠 |
| mtb_07d1 | 피곤함, 기력저하 |
| mtb_07e1 | 식욕 저하 혹은 과식 |
| mtb_07f1 | 내 자신이 나쁜 사람이라는 느낌 |
| mtb_07g1 | 신문이나 TV 집중 어려움 |
| mtb_07h1 | 거동이나 말이 느림 |
| mtb_07i1 | 죽는 것이 낫겠다는 생각 |

→ 9문항 합산 **≥10 = 현재 우울** (NHANES DPQ010–090과 동일 정의).

## 3. ★ PHQ-9 가용 연도 — 확정
**2017 · 2018 · 2019 · 2020 · 2021 · 2022 · 2023 · 2024 · 2025 (매년, 9개년)**

- **2008–2016**: 9문항 PHQ-9 **없음** — 단일문항 `mtb_01z1`(우울감 경험)만 있음 → 이 연구엔 사용 불가.
- 2009년만 예외적으로 20문항 별도 선별조사(`mtf_01z1`~`mtf_20z1`)가 있으나 PHQ-9 아님.

## 4. 기타 우울 관련 변수 (참고)
- `mtb_01z1` 우울감 경험(단일문항) — 전 연도, 민감도용
- `mtb_02z1` 우울증상 정신상담 여부
- `qoc_05z1` EQ-5D 불안/우울 차원 — NHANES에 없음(국내모델 전용)
- `dpa_02z1` 우울증 의사진단 여부 — **2009–2013년만** 존재

## 5. 분석 전 확인/주의
- **PHQ-9 응답 코딩(0–3 vs 1–4)**: 실제 값 라벨을 확인 후 0–3으로 재코딩해 합산(아웃컴 스크립트에서 처리).
- **'우울증 기왕력 제외' 민감도분석**: 2017+ 최근 연도엔 우울증 의사진단(`dpa_*`) 변수가 안 보임 → KCHS에서 제한적일 수 있음(조사표/이용지침서 재확인 필요).
- 예측변수(연령·성별·교육·소득·흡연·음주·신체활동·수면·BMI·자가건강·고혈압·당뇨)의 연도별 실제 코드는 다음 단계(변수 조화)에서 이용지침서로 매핑.
