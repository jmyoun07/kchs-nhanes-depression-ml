# 모델 카드 — 우울 스크리닝(PHQ-9≥10) 조화모델

TRIPOD+AI(2024)·PROBAST 준거. **예비(preliminary) — OSF 사전등록 후 확정.** 최종 갱신 2026-07-10.

## 1. 모델 개요
- **유형/알고리즘**: 이진 분류(현재 우울, PHQ-9 총점 ≥10). 후보 3종(penalized logistic·random forest·LightGBM) 중 **주 모델 = LightGBM** (사전기준: CV-AUROC → |보정slope−1| → 간명성).
- **개발 데이터**: 한국 지역사회건강조사(KCHS) 2017–2025, 성인 20+·PHQ-9 완결, n=2,048,510 (복합표본 가중).
- **예측변수 14개(프로토콜 Table 1)**: 연령·성별·교육·소득(설문내 분위)·유배우·독거·흡연·음주·신체활동·수면·BMI·**자가건강**·고혈압·당뇨. (인종=공정성 하위군 전용)
- **전처리**: 개발셋에서만 학습(median/최빈 대체·표준화·원핫), 외부셋에 그대로 적용(누수 방지).

## 2. 용도
- **스크리닝/트리아지 보조 도구** — 저위험자는 자기관리 자원, 고위험자는 전문평가로 라우팅. **진단·단독 임상판단 도구 아님.**
- 저부담 웹/모바일 자가문진(경량 4문항 버전: 자가건강·나이·성별·수면 AUROC 0.82).

## 4. 공정성

## 5. 한계·주의
- **예비**(OSF 전). **자가건강 NHANES 매핑 정정**(HSQ→HUQ010, erratum). 범주 앵커 문화차는 서열형 처리.
- **NHANES post DPQ 무응답 32.7%** → post 결과 완전례 한정.
- 자가보고(KCHS BMI·행동) vs 실측(NHANES BMI); 단면 설계(현재 증상 스크리닝, 미래 발병 예측 아님).
- **PPV 낮음(0.08–0.19)** → 위양성 부담. 임상 유용성은 전향 검증 후.
- 재보정은 목표시기 라벨 필요; pre→post 전이 수준 offset 잔존.
- 연령 20+ 대상. 음주·신체활동 도구차이(민감도서 제외해도 0.824→0.823 강건).
