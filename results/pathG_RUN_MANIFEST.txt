   → 17변수는 KCHS에서 0.80 이상 신호를 가지나 NHANES에서는 ~0.77이 한계.
3) 단변량: 최강예측인자 srh 가중AUROC KCHS 0.757 → NHANES 0.697/0.681.
   → 예측인자-우울 관계가 NHANES에서 본질적으로 약함(공변량이동으로 교정불가).

   pre 0.774 [0.748, 0.797] P(≥0.80)=1.1%
   post 0.765 [0.743, 0.787] P(≥0.80)=0.0%
   → 95% 상한도 0.80 미달.

protocol_compliant 판정:
  - IW/CORAL/트리밍/불변특징/raking/조합은 모두 NHANES 공변량(분포)을 학습에 사용
    → §2.10 라벨은 안 쓰나 배포시 타깃 공변량 필요 → 배포현실성 제약, False로 판정.
    (raking의 인구 마진만은 공개통계로도 근사 가능해 상대적으로 현실성 높음 — note 명시)
  - living_alone은 NHANES pre에서 100% 결측(구조적)이라 도메인분류기 AUC=1.0 붕괴의 원인.
    도메인분류기에서 제외(noLA)해야 IW가 동작. dropLA/LAmask는 사실상 17→16변수라 변수고정 제약과 충돌 → False.
  - 오라클/동일표본 상한, 단변량은 진단 전용(라벨 사용 또는 배포불가) → False.
